# Weather App 🌦️

## Description
A beginner-friendly Python weather application that displays real-time weather information for any city using the OpenWeatherMap API.

## Features
- Search weather by city name
- Display temperature in Celsius
- Show current weather conditions

## Technologies Used
- Python
- Requests Library
- OpenWeatherMap API

## Installation
1. Install Python
2. Install requests:
   pip install requests
3. Add your API key in weather.py
4. Run:
   python weather.py
